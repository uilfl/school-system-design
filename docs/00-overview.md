# 學校 SaaS 系統 - 整體概述

## 系統願景

打造一個可延伸、模組化的學校管理 SaaS 平台，服務從小學到大學的各類教育機構。

## 核心價值主張

1. **多租戶架構** - 一套系統服務多所學校，每所學校獨立資料空間
2. **模組化設計** - 學校可依需求啟用/停用功能模組
3. **可延伸性** - 開放 API 與 Webhook，支援第三方整合
4. **權限精細化** - 基於角色的存取控制（RBAC），確保資料安全
5. **跨平台支援** - Web、Mobile App、API 多管道存取

## 系統架構三層式設計

```
┌─────────────────────────────────────────────────────────────┐
│                       擴充 / 整合層                          │
│  • Open API & Webhook  • Plugin System  • Custom Workflow   │
└─────────────────────────────────────────────────────────────┘
                              ▲
                              │
┌─────────────────────────────────────────────────────────────┐
│                      學校營運核心模組                         │
│  • 學籍管理(SIS)    • 課程&課表    • 成績評量               │
│  • 出缺勤管理       • 家校溝通     • 財務管理               │
└─────────────────────────────────────────────────────────────┘
                              ▲
                              │
┌─────────────────────────────────────────────────────────────┐
│                        共用平台層                            │
│  • 多租戶架構  • IAM/RBAC  • 設定中心  • 通知中心  • 稽核   │
└─────────────────────────────────────────────────────────────┘
```

## 目標用戶角色

| 角色 | 主要需求 |
|------|---------|
| 校方管理員 | 系統設定、用戶管理、報表分析 |
| 教務人員 | 課程規劃、成績管理、學籍管理 |
| 教師 | 課表查詢、點名、成績輸入、學生溝通 |
| 學生 | 課表查詢、成績查詢、作業繳交 |
| 家長 | 子女成績、出勤、學校通知 |
| 系統管理員 | 租戶管理、系統監控、資料備份 |

## 技術棧概覽

### 後端
- **語言**: Node.js + TypeScript
- **框架**: Express.js / Nest.js
- **資料庫**: PostgreSQL (主資料庫) + Redis (快取)
- **ORM**: Prisma / TypeORM
- **認證**: JWT + OAuth 2.0

### 前端
- **框架**: React + TypeScript
- **狀態管理**: Redux Toolkit / Zustand
- **UI 框架**: Material-UI / Ant Design
- **API 通訊**: React Query + Axios

### 基礎設施
- **容器化**: Docker + Docker Compose
- **CI/CD**: GitHub Actions
- **監控**: Prometheus + Grafana
- **日誌**: ELK Stack (Elasticsearch, Logstash, Kibana)

## MVP (最小可行產品) 範圍

### Phase 1 功能
1. ✅ 平台層基礎
   - 多租戶架構
   - 用戶認證與授權
   - 基本權限管理

2. ✅ 核心模組（3個）
   - 學籍管理系統 (SIS)
   - 課程與課表管理
   - 出缺勤管理

3. ✅ 基礎 UI
   - 管理員後台
   - 教師工作台
   - 學生門戶
